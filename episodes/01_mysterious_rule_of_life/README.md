# Episode 1: The mysterious rule of life

> *What has changed in the pixel universe?*

A rule in Conway's Game of Life has changed, and nobody knows yet what the change is.
Your task is to find out by running experiments.

Conceived and written by Soeren Arlt (MPL), slightly updated by Florian Marquardt.

## Files

- `wiki_page.md`: the episode description from the wiki (HedgeDoc markdown), with the team
  entries removed.
- `Episode1.ipynb`: the notebook. Draw an initial configuration, then compare the standard Conway
  simulation with the "observed" evolution in the modified universe.
- `Episode1_life_helper.py`: simulation routines used by the notebook. It must be in the same folder
  as the notebook.

## Running it

Open `Episode1.ipynb` in VS Code or Jupyter and run the cells from top to bottom. The drawing grid
uses `ipywidgets`, see [SETUP.md](../../SETUP.md).
