# Example episode: Physics on a swing

> *A harmonic oscillator with a time-dependent spring constant: What happens?*

This is an **example** of what the joint wiki looks like during an episode. It is not a real episode.
Use it as a guide to the format: listing teams, collecting and ranking questions, posting signed
and time-stamped research progress (with figures and code), summarising one key message, and
collecting questions for the future.

- `wiki_page.md`: the example wiki page (HedgeDoc markdown).
- `figures/`: the plots embedded in the example.

Note: blocks like `:::info … :::` are HedgeDoc syntax. They render as coloured boxes on the pad,
but as plain text on GitHub.
